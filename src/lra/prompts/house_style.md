# House style

The firm's own drafting conventions. Replace this file with them.

Once this file is replaced, its contents go into the system prompt of every
review and every comparison (`versions.house_style`). Until then nothing is
sent: the template below is advice to you, not to the model, and the first line
of this file is how the code tells the two apart. Keep that line out of your
version.

DECISIONS #7 settles house style as mostly learned rather than written. The
learned half is `memory.py`: what a lawyer undoes and what they ask not to be
told about. This file is for the conventions a firm already has written down.

Things worth putting here:

- Preferred terms: "will" vs "shall", "Agreement" vs "agreement"
- Date format: "January 1, 2026" vs "1 January 2026"
- Number style: when to spell out, when to use both words and numerals
- Defined-term conventions: bold, quoted, capitalized
- Numbering scheme for sections, subsections, schedules
- Signature block format
- Clauses that always need a second look before going out
- Language the firm never uses
